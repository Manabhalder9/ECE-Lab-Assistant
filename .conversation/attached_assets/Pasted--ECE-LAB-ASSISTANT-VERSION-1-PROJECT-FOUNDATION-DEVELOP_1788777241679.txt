ECE Lab Assistant is a simple web-based toolkit for Electronics & Communication Engineering students.

The purpose is to provide commonly used ECE calculators and small interactive tools in one clean interface.

The application should feel like a small, polished engineering tool rather than a basic college HTML assignment.

The final application will contain:

# 14. IMPORTANT RESISTOR REQUIREMENT

The resistor calculator is especially important.

It MUST use dropdown/select controls.

For a 4-band resistor:

```text
Band 1 → First significant digit
Band 2 → Second significant digit
Band 3 → Multiplier
Band 4 → Tolerance
```

For a 5-band resistor:

```text
Band 1 → First significant digit
Band 2 → Second significant digit
Band 3 → Third significant digit
Band 4 → Multiplier
Band 5 → Tolerance
```

Digit/multiplier colors:

* Black
* Brown
* Red
* Orange
* Yellow
* Green
* Blue
* Violet
* Grey
* White

Tolerance colors:

* Brown → ±1%
* Red → ±2%
* Green → ±0.5%
* Blue → ±0.25%
* Violet → ±0.1%
* Grey → ±0.05%
* Gold → ±5%
* Silver → ±10%

Example:

```text
Red
Violet
Red
Gold
```

should calculate:

```text
2.7 kΩ ±5%
```

Example 5-band:

```text
Brown
Black
Black
Red
Brown
```

should calculate:

```text
1.00 kΩ ±1%
```

The application should also display a simple resistor illustration using HTML/CSS if practical.

The illustration should automatically change between:

* 4 bands
* 5 bands

based on the selected resistor type.
