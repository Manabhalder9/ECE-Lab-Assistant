Number System Basics

  • Binary: Base 2 and uses 0 and 1.
  • Decimal: Base 10 and uses digits 0–9.
  • Octal: Base 8 and uses digits 0–7.
  • Hexadecimal: Base 16 and uses 0–9 and A–F.

Logic Gate Basics

  • A logic gate is a digital circuit that performs a Boolean operation.
  • Inputs are binary values: 0 or 1.
  • AND: Output is 1 only when all inputs are 1.
  • OR: Output is 1 when at least one input is 1.
  • NOT: Reverses the input.
  • NAND: The inverse of AND.
  • NOR: The inverse of OR.
  • XOR: Output is 1 when inputs are different.
  • XNOR: Output is 1 when inputs are the same.

After approximately 5τ, a capacitor is considered practically fully charged or discharged.

RC Circuit Formulas

  • Time Constant: τ = R × C
  • Charging Voltage: V(t) = V₀(1 − e⁻ᵗ/τ)
  • Discharging Voltage: V(t) = V₀e⁻ᵗ/τ

Time Constant Interpretation

  • 1τ → about 63.2% charged / 36.8% remains
  • 2τ → about 86.5% charged / 13.5% remains
  • 3τ → about 95.0% charged / 5.0% remains
  • 4τ → about 98.2% charged / 1.8% remains
  • 5τ → about 99.3% charged / 0.7% remains
