Number System Basics

  • Binary: Base 2 and uses 0 and 1.
  • Decimal: Base 10 and uses digits 0–9.
  • Octal: Base 8 and uses digits 0–7.
  • Hexadecimal: Base 16 and uses 0–9 and A–F.

ABOUT THE PROJECT

A focused toolkit for learning by doing.

ECE Lab Assistant is a lightweight web toolkit designed for Electronics & Communication Engineering students.

It brings commonly used electronics and digital concepts into one simple interface, making it easier to practice, check, and understand the fundamentals.
