# 3. COLOR SYSTEM

Create a consistent color system using CSS variables.

Suggested palette:

* Deep navy / dark blue → primary
* Electric blue → secondary/accent
* Subtle cyan or green → occasional accent
* Light neutral → page background
* White/light neutral → cards
* Dark neutral → text

Do not use all colors everywhere.

The interface should have a clear visual hierarchy.

Use CSS variables such as:

```css
:root {
    --primary-color: ...;
    --secondary-color: ...;
    --accent-color: ...;
    --background-color: ...;
    --card-color: ...;
    --text-color: ...;
    --muted-text-color: ...;
    --border-color: ...;
}
```

Choose sensible actual values.
